# Методология карьерного консультанта

## Цель работы

Помочь клиенту пройти карьерный переход осознанно и практично: уточнить цель, собрать позиционирование, выбрать направление, подготовить резюме/LinkedIn и план действий.

## Этапы работы

### 1. Вводный звонок

Цель: понять запрос клиента, текущую ситуацию, уровень позиции, индустрию, риски и потенциальный формат услуги.

Codex помогает:

- сохранить транскрипт в папку клиента;
- сделать конспект;
- выделить цели, проблемы, риски, уровень позиции и возможные услуги;
- собрать все входящие материалы в одну папку.

Живая работа:

- провести разговор;
- почувствовать мотивацию и контекст;
- решить, что клиенту действительно нужно.

### 2. Предложение клиенту

Цель: подготовить понятное предложение после звонка.

Codex помогает:

- собрать черновик предложения из конспекта;
- подготовить письмо вокруг предложения;
- использовать шаблоны "одна сессия" / "пакет".

Живая работа:

- решить, что предложить именно этому клиенту;
- вычитать письмо перед отправкой.

### 3. Подключение клиента

Цель: после согласия клиента собрать оплату, анкету, резюме и стартовые материалы.

Codex помогает:

- вести чек-лист подключения;
- готовить приветственное письмо;
- раскладывать резюме, ответы анкеты и файлы по папке клиента.

Позже можно подключить:

- Google Forms;
- Gmail;
- Google Drive;
- Calendar/Meet.

### 4. Тест сильных сторон

Цель: пригласить клиента на тест, отследить статус и сохранить результаты.

Codex помогает:

- готовить письмо со ссылкой;
- вести таблицу статусов;
- делать сводку результатов теста.

Внешняя интеграция со сторонним тестом - отдельная задача для подрядчика или API.

### 5. Карьерная стратегия

Цель: собрать стратегию на основе всех источников: звонок, анкета, резюме, LinkedIn, тест, вакансии.

Codex помогает:

- собрать пять источников в один рабочий контекст;
- подготовить черновик стратегии;
- выделить сильные стороны, позиционирование, направления, риски, рыночные гипотезы;
- разложить результат по шаблону документа.

Живая работа:

- выбрать, какое направление рекомендовать;
- переписать стратегию под конкретного человека.

### 6. Разбор вакансий

Цель: понять рынок, требования, разрывы навыков, ключевые слова и зарплатные ориентиры.

Codex помогает:

- анализировать пачку описаний вакансий;
- выделять повторяющиеся требования;
- сравнивать требования с резюме клиента;
- собирать ключевые слова для резюме.

Подрядчик/API нужны только для автоматического сбора вакансий с сайтов.

### 7. Переписывание резюме

Цель: подготовить черновик резюме под выбранную позицию.

Codex помогает:

- использовать выводы из разбора вакансий;
- подготовить черновик резюме;
- хранить версии под разные роли;
- подсветить места, где нужны факты и цифры от клиента.

Живая работа:

- решить, что оставить и что убрать;
- провести сессию по резюме;
- финально утвердить текст.

### 8. Профиль LinkedIn

Цель: подготовить заголовок, About, рекомендации по профилю и чек-лист проверки.

Codex помогает:

- готовить варианты заголовка и раздела About;
- оценивать профиль по чек-листу;
- выгружать рекомендации для клиента.

Живая работа:

- клиент обновляет профиль сам или вместе с консультантом;
- консультант проверяет, как человек выглядит профессионально.

### 9. Итоговый отчет и план действий

Цель: собрать финальный отчет, план действий и 2-3 следующих шага.

Codex помогает:

- пройти по всей папке клиента;
- собрать сводный отчет;
- подготовить план действий;
- сделать короткую выжимку для клиента.

Живая работа:

- финальная вычитка;
- решение, что клиент действительно должен увидеть.

## Уровни автоматизации

- Шаблон: готовый текст или структура для ручного заполнения.
- Ассистент: Codex готовит черновик по данным, которые ему дали.
- Агент с файлами: Codex сам читает папку клиента и собирает результат из нескольких источников.
- По расписанию: проверка статусов, напоминания, регулярные обзоры.
- Живая работа: экспертное решение и контакт с клиентом.
- Подрядчик: парсинг сайтов, API, сложные дашборды, интеграции.

## Главное правило

Автоматизируем не профессию, а обслуживание профессии.

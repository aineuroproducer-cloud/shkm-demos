# Клиентские кейсы

Каждый клиент хранится в отдельной папке.

Рекомендуемая структура:

```text
clients/client-name/
  00-profile.md
  01-intro-call.md
  02-proposal.md
  03-onboarding.md
  04-strengths.md
  05-strategy.md
  06-vacancies.md
  07-resume.md
  08-linkedin.md
  09-final-report.md
  source/
```

В `source/` кладутся исходники: резюме, анкета, транскрипт, вакансии, результаты тестов.

Для учебных примеров используйте обезличенные данные.

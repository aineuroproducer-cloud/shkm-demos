# Демо-клиент

Папка для первого учебного кейса.

Положите сюда обезличенные материалы:

- резюме;
- транскрипт вводного звонка;
- анкету;
- 3-5 вакансий;
- LinkedIn-профиль в виде текста или скриншотов;
- результаты теста сильных сторон, если есть.

Затем попросите Codex собрать профиль клиента по шаблону `templates/00-client-profile-template.md`.

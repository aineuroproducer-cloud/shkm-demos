# Career Command Center - шаблон проекта Codex

Это учебный шаблон командного центра карьерного консультанта.

Главная идея: сначала отработать процесс на папке и файлах, затем подключать коннекторы Google Drive, Gmail, Calendar, Meet или Make только для уже понятных повторяющихся шагов.

## Как использовать

1. Скопировать эту папку в отдельный проект Codex.
2. Открыть проект в Codex.
3. Дать Codex первый запрос из `FIRST_PROMPT.md`.
4. Положить в `clients/_demo-client/` один обезличенный кейс: резюме, транскрипт звонка, анкету, вакансии.
5. Попросить Codex собрать профиль клиента, стратегию, черновик резюме и итоговый отчет.
6. Проверить результат руками и поправить методологию/шаблоны.

## Что здесь есть

- `AGENTS.md` - правила работы ассистента.
- `memory/methodology.md` - методология карьерного консультанта.
- `templates/` - повторяющиеся документы по 9 этапам.
- `clients/` - папки клиентских кейсов.
- `work/status.md` - текущие задачи и статусы.
- `logs/change-log.md` - журнал важных изменений.

## Граница автоматизации

Codex может читать, анализировать, готовить черновики и предлагать.

Отправка писем, публикации, изменение внешних сервисов, работа с реальными персональными данными, финансовые действия и доступы - только после явного подтверждения пользователя.

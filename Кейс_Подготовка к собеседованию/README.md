# Career Intake Agent

Учебный агент для модуля **«AI-ассистенты и автоматизация»** Школы карьерного менеджмента.

Показывает третий, самый глубокий уровень автоматизации — **вайбкодинг настоящего агента**:
то, до чего можно дорасти после Claude Cowork, или отдать разработчику с готовым ТЗ.

Агент обходит папки клиентов, читает транскрипт звонка (+ CV или анкету), формирует
**Client Profile** и **черновик письма-предложения**, раскладывает результат по папкам
и печатает отчёт.

> Демо-клиенты (Дмитрий Корнев, Анна Мельникова) — полностью вымышленные персонажи,
> придуманные для курса. Никаких реальных данных здесь нет.

---

## Быстрый старт (демо-режим — без ключей и интернета)

```bash
git clone <ссылка-на-этот-репозиторий>
cd career-intake-agent
python agent.py
```

Демо-режим не требует API-ключа — результат берётся из `fixtures.json` (готовый анализ
Дмитрия и Анны). Откройте `demo-clients/Клиент_1_Дмитрий_Корнев/client_profile.md` — вот
результат.

Хотите пройти путь заново с чистого листа:

```bash
python reset_demo.py   # удаляет сгенерированные client_profile.md и proposal_draft.md
python agent.py        # и снова создаёт их на глазах
```

## Боевой режим (любой транскрипт, реальный анализ Claude)

```bash
pip install anthropic
export ANTHROPIC_API_KEY=sk-ant-...      # Windows PowerShell: $env:ANTHROPIC_API_KEY="sk-ant-..."
python agent.py --live
```

Положите свой транскрипт в `demo-clients/Мой_Клиент/transcript.txt` (можно и `cv.txt` /
`anketa.txt` рядом) — и агент проанализирует его по-настоящему через Claude API.

Полезные флаги:
- `--folder "Клиент_1_Дмитрий_Корнев"` — обработать только одну папку
- `--force` — перезаписать уже существующий профиль
- `--clients-dir путь` — указать другую папку с клиентами

## Что показывает этот агент

| | Make.com | Этот агент |
|---|---|---|
| Кто собирает | визуально, мышкой из модулей | **вайбкодинг** — описал задачу словами, Claude Code написал код |
| Логика | в пределах готовых модулей | любые условия: «нет CV — пропусти», «профиль уже есть — не трогай», «ошибка — сообщи, не падай» |
| Стоимость | подписка $9–16/мес | только токены API — центы за запуск |
| Зависимости | внешний сервис + связка API | один Python-файл |

**Агент — это когда система сама принимает решения, а не просто выполняет шаги.**
Это видно прямо в коде: папки без транскрипта пропускаются, готовые профили не
перезаписываются без `--force`, ошибка одного клиента не останавливает обработку остальных.

## Как этот агент появился

Никто не писал этот код руками. Техническое задание — [`TZ.md`](./TZ.md) — отдали Claude Code
с фразой «реализуй агента по этому ТЗ», и инструмент написал, запустил и отладил код сам.
Чтобы собрать такого агента, не нужно уметь программировать — нужно уметь **понятно описать
процесс**.

## Как расширить до полной версии (Google Workspace)

В этом учебном агенте результат сохраняется в локальные `.md`-файлы рядом с клиентом.
Чтобы превратить его в систему из полного ТЗ — с папкой в Google Drive, документом
Client Profile и черновиком письма прямо в Gmail — в функцию `save_outputs()` добавляются
вызовы Google API. Это тоже делается вайбкодингом: «добавь сохранение в Google Drive и
черновик в Gmail» — и Claude Code допишет интеграцию. Список нужных пакетов уже есть в
`requirements.txt`.

## Файлы

```
career-intake-agent/
├── agent.py           # весь агент: чтение → анализ → сохранение → отчёт
├── reset_demo.py       # сбросить демо-результаты и пройти путь заново
├── fixtures.json       # готовый анализ для демо-режима (Дмитрий, Анна)
├── requirements.txt    # зависимости (демо-режим работает и без них)
├── TZ.md                # исходное техническое задание, по которому агент собран
└── demo-clients/
    ├── Клиент_1_Дмитрий_Корнев/   (transcript.txt, cv.txt)
    └── Клиент_2_Анна_Мельникова/  (transcript.txt, anketa.txt)
```

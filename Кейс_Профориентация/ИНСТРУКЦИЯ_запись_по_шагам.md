> 📁 Все файлы — в папке `Модуль_профориентация`. Демо-клиенты — в `demo-clients`

# ЭТАП 3. ЗАПИСЬ — поминутно
Слева — что **делаешь руками**, в кавычках — что **говоришь**.

## БЛОК 1 — Концепция (20 мин) · слайды
Открываешь `презентация-профориентация.pptx` на весь экран.

1. **Титул + «О чём урок».**
   > «Берём реальный процесс профориентатора: подросток проходит тест Digital Human, вы
   > получаете отчёт, анализируете, строите гипотезы, проверяете на встрече, готовите итоговый
   > отчёт. Смотрим, что здесь можно отдать AI.»
2. **Главный вопрос.**
   > «Вопрос не "какой инструмент", а "что рутина, а что — моя экспертиза".»
3. **Три роли (профориентатор / AI / автоматизация).**
   > «Гипотезы проверяете вы, итоговый отчёт правите вы. AI снимает рутину и черновую аналитику.»
4. **Развилка + три уровня.**
   > «Два способа: соединять сервисы (Make) или описать словами, и AI соберёт инструмент —
   > вайбкодинг. Для анализа отчётов берём вайбкодинг. Покажу три уровня.»

## БЛОК 2 — Уровень 1: Cowork (25 мин)
**2а. Ручной режим (8 мин).** Открываешь папку `demo-clients` в Cowork. Вставляешь в чат текст
отчёта Ясмины (`Подросток_Ясмина/профориентационный_отчет.txt`) + промпт из `prompts/01_анализ_отчета.md`.
> «Cowork прочитал отчёт, собрал профиль, сильные стороны, гипотезы и вопросы к встрече — и
> положил файл в папку. Это 20–30 минут вашей работы.»

**2б. Проект (12 мин).** Создаёшь проект, подключаешь папку, вставляешь
`demo-clients/ИНСТРУКЦИЯ_ДЛЯ_ПРОЕКТА.md` как инструкцию. Пишешь: `Обработай все папки клиентов`.
> «Теперь у ассистента постоянная память. Он сам обходит папки, отличает подростковый отчёт от
> взрослого, готовые пропускает.»

**2в. Расписание (5 мин).** Настраиваешь Scheduled task на вечер.
> «Провели за день 3 консультации — вечером Cowork сам обработал новые отчёты. И новость:
> Cowork теперь есть в браузере и на телефоне, задачи можно запускать откуда угодно. Работа с
> локальными папками пока в десктопе, но всё идёт в облако.»

## БЛОК 3 — Уровень 2: веб-кнопка (12 мин)
Открываешь `otchet-workbench.html` (или ссылку GitHub Pages).
1. Кнопка «Ясмина» → поля заполнились.
2. «Проанализировать» → вкладка «Анализ и гипотезы».
3. Вкладка «Итоговый отчёт» → черновик отчёта-презентации.
4. «Скачать .md».
> «Я сказала AI: сделай страницу, куда вставляю отчёт и получаю анализ и черновик итогового
> отчёта. Вот она. Программиста не было. Можно отдать коллегам.»
Показываешь ⚙️: «свой ключ → работает с любым отчётом».

## БЛОК 4 — Уровень 3: агент (12 мин)
В терминале VS Code (при желании сначала `python reset_demo.py`):
```
cd profori-agent
python agent.py
```
Показываешь: агент обходит папки, создаёт анализ и итоговые отчёты.
> «Этого кода я не писала. Дала Claude Code или Codex описание задачи — он написал программу.
> Codex от OpenAI — тот же класс инструмента: терминал, IDE, облако. Это уровень "дорасти или
> отдать спецу", но ТЗ у вас уже есть.»

## БЛОК 5 — Cowork/Codex/Make (6 мин)
Открываешь `сравнение-инструментов.md` (или слайд).
> «Cowork и Codex работают с вашими файлами по описанию. Make — когда автоматизация должна
> запускаться сама, по событию (заполнили форму записи → создалась карточка). Для анализа
> отчётов достаточно Cowork.»

## БЛОК 6 — Итог и ДЗ (5 мин)
> «Три уровня: Cowork сегодня → своя кнопка по фразе → настоящий агент.»
**ДЗ:** взять один обезличенный отчёт, прогнать через Cowork с промптом из урока. Кто дальше —
воркбенч + свой ключ. Результат в чат.
**Отдаёшь в чат:** `РАЗДАТКА_студентам.md`, папку `prompts/`, `otchet-workbench.html`.

# 🆘 Если что-то пошло не так
| Проблема | Решение |
|---|---|
| `python` не распознан | Попробуй `python3`. Нет Python — пропусти блок 4, покажи готовый результат. |
| Агент: «пропущено — анализ уже есть» | `python reset_demo.py`, затем `python agent.py`. |
| Воркбенч не генерит своего клиента | Без ключа работают только Ясмина и Максим. Для своих — ключ в ⚙️. |
| Cowork долго думает | Скажи «обрабатывает» — это часть демо, выглядит честно. |

# Раздатка: автоматизируй профориентацию вайбкодингом
## Школа карьерного менеджмента · модуль «Ассистенты и агенты»

Вайбкодинг — это **не «научиться программировать»**, а **понятно описать задачу**. Код пишет AI.
Три уровня. Начни с первого — он работает уже сегодня.

---

## Что в комплекте
1. `otchet-workbench.html` — веб-инструмент: вставил отчёт → получил анализ + черновик итогового отчёта.
2. `profori-agent/` — код агента + README (уровень 3).
3. `prompts/` — 3 промпта: анализ отчёта, вопросы к встрече, итоговый отчёт.
4. `demo-clients/ИНСТРУКЦИЯ_ДЛЯ_ПРОЕКТА.md` — системная инструкция для проекта Cowork.

---

## Уровень 1 — Claude Cowork (сегодня, без кода)
1. Подписка Claude → открой Cowork. (Cowork теперь и в браузере/на телефоне — beta, тариф Max;
   работа с локальными папками пока в десктопе.)
2. Подключи папку с файлами клиента (отчёт, контекст встречи).
3. Вставь промпт из `prompts/01_анализ_отчета.md` и текст отчёта.
**По расписанию:** создай проект, вставь `ИНСТРУКЦИЯ_ДЛЯ_ПРОЕКТА.md`, настрой Scheduled task на вечер.

## Уровень 2 — своя «кнопка» (без терминала)
**Готовый инструмент:** открой `otchet-workbench.html`, нажми ⚙️, вставь API-ключ
(console.anthropic.com → API Keys, 30 секунд) — и он анализирует любой отчёт.
**Собрать свой с нуля (вайбкодинг):** открой Claude / Codex / AI Studio и напиши:
```
Сделай одностраничный HTML-инструмент для профориентатора.
Слева — поле, куда я вставляю текст профориентационного отчёта и контекст встречи.
По кнопке — отправляй в Claude API и показывай справа:
1) анализ отчёта с гипотезами и вопросами к встрече,
2) черновик итогового отчёта.
Кнопки «копировать» и «скачать .md». Весь код — в одном файле.
```
Не нравится — просишь доработать словами. Это и есть вайбкодинг.

## Уровень 3 — настоящий агент (для смелых или на аутсорс)
Терминал: Claude Code или **OpenAI Codex** (CLI / расширение VS Code / облако). Либо отдай
разработчику — ТЗ у тебя уже есть.
```
cd profori-agent
python3 agent.py        # демо без ключей
python3 agent.py --live # боевой режим (нужен ANTHROPIC_API_KEY)
```
Агент обходит все папки, отличает подростковый отчёт от взрослого, готовые пропускает,
при ошибке повторяет. Это логика, а не один шаг.

## Как выбрать свой уровень
| Если ты… | Начни с |
|---|---|
| хочешь результат сегодня | **Уровень 1 (Cowork)** |
| хочешь «кнопку» для себя/коллег | **Уровень 2 (веб-инструмент)** |
| готова к терминалу или есть спец | **Уровень 3 (Codex / Claude Code)** |

Make.com не нужен для анализа отчётов — он для триггеров (форма записи → карточка). Подробнее —
`сравнение-инструментов.md`.

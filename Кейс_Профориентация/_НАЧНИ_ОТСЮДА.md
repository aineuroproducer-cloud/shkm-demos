# Модуль «Ассистенты и агенты» для профориентатора — старт отсюда

Демо-кейс — анализ профориентационного отчёта (методика Digital Human). Всё крутится вокруг
двух демо-клиентов: **Подросток (Ясмина, 16)** и **Взрослый (Максим, 34)**.

## С чего начать тебе лично
1. Открой **`ИНСТРУКЦИЯ_запись_по_шагам.md`** — главный документ «по рельсам».
2. Пройди этап 0 (подготовка) и этап 1 (репетиция) без камеры.
3. Этап 2 (сброс) → записывай.

## Структура урока
Концепция → Cowork (ручной → проект → расписание) → веб-кнопка → агент (Codex/Claude Code) →
Cowork/Codex/Make → итог.

## Быстрая проверка
```
cd profori-agent
python agent.py --force     # ✅ Ясмина, ✅ Максим
```
Открой `otchet-workbench.html` → «Ясмина» → «Проанализировать» → должен появиться анализ.

> Перед демо Cowork: `python reset_demo.py` — очистит сгенерированные файлы, чтобы показать
> создание с нуля.

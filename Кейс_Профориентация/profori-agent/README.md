# Профориентация — агент обработки папок

Учебный агент для модуля «Ассистенты и агенты» ШКМ. Уровень «настоящий агент»
(Cowork/Codex → или Python по ТЗ). Обходит папки клиентов, читает
профориентационный отчёт + контекст встречи, создаёт **анализ с гипотезами** (до сессии)
и **черновик итогового отчёта** (после сессии).

## Быстрый старт (демо-режим, без ключей — для записи)
```bash
cd profori-agent
python3 agent.py          # обработает Подростка и Взрослого
python3 agent.py --force  # перезаписать
python3 reset_demo.py     # обнулить перед показом с нуля
```
Демо берёт готовый анализ из `fixtures.json` — работает без интернета и ключей.

## Боевой режим (любой клиент)
```bash
pip install anthropic
export ANTHROPIC_API_KEY=sk-ant-...
python3 agent.py --live
```

## Что показывает
Логику, которой нет у простого чата: обойти все папки, пропустить готовые, отличить
подростковый отчёт от взрослого, при отсутствии контекста — пометить пробелы. Это и есть
разница между «ассистент отвечает» и «агент действует».

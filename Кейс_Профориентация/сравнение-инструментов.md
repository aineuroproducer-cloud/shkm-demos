# Cowork · Codex · Make — что когда выбирать
## Для профориентатора, простыми словами. Актуально на июль 2026.

Три уровня автоматизации из урока — и чем их собирать.

---

## Коротко

- **Claude Cowork** — десктопный AI-ассистент: подключаешь папку с файлами клиентов, он читает
  отчёты, пишет анализ и итоговые отчёты, раскладывает по папкам. Без кода, без API.
  С июля 2026 Cowork есть и в браузере/на телефоне (beta, тариф Max) — можно запускать и
  продолжать задачи откуда угодно. Но работа с **локальными папками и расписание пока в
  десктоп-приложении**.
- **OpenAI Codex** — «взрослый» агент для файлов и кода: терминал (CLI), расширение для
  VS Code, облачные задачи, версия в ChatGPT. Один аккаунт, работает на GPT-5.5.
  Аналог Claude Code. Для профориентатора — уровень «дорасти или отдать спецу».
- **Make.com** — конструктор автоматизаций с триггерами: реагирует на внешнее событие
  (заполнена форма, пришёл файл). Нужен, когда процесс должен запускаться сам, без тебя.

Для задачи «проанализируй отчёт и собери документы» **вайбкодинг (Cowork/Codex) короче и
дешевле**. Make — для триггеров и связки чужих сервисов.

## Таблица

| Критерий | Claude Cowork | OpenAI Codex | Make.com |
|---|---|---|---|
| **Что это** | Десктоп-ассистент с файлами | Агент CLI/IDE/облако | Конструктор с триггерами |
| **Кто собирает** | Ты, словами | Ты словами + терминал/IDE | Ты, мышкой из модулей |
| **Нужен код/терминал** | Нет | Да (или отдать спецу) | Нет |
| **Работа с папками клиентов** | ✅ (десктоп) | ✅ | Через Google Drive |
| **Запуск по событию (триггер)** | Нет (расписание/вручную) | Нет (ты запускаешь) | ✅ Сильная сторона |
| **Браузер/мобайл** | Чат и удалённые задачи (beta, Max) | Облако + ChatGPT | Полностью в браузере |
| **Стоимость** | Подписка Claude | Подписка/токены OpenAI | Free; Core $9; Pro $16 |
| **Кому** | Профориентатор сам | Продвинутый / разработчик | Профориентатор или подрядчик |

## Как это ложится на процесс профориентатора

| Задача | Чем закрыть |
|---|---|
| Анализ профориентационного отчёта → гипотезы | **Cowork / веб-воркбенч** (уровень 1–2) |
| Вопросы к встрече по чек-листу | **Cowork / промпт** |
| Обработать сразу все отчёты за день | **Cowork-проект + расписание** или **агент (Codex)** (уровень 3) |
| Итоговый отчёт-презентация после консультации | **Cowork / воркбенч** по шаблону |
| Форма записи на консультацию → таблица → письмо | **Make.com** (триггер) |
| Ежедневный мониторинг / телеграм-бот | Уровень 3–4 — **аутсорс** |

## Одна фраза для слайда

> «Cowork и Codex работают прямо с вашими файлами — вы описываете задачу, агент делает.
> Make нужен, когда автоматизация должна запускаться сама, по событию. Для анализа отчётов и
> сборки документов достаточно Cowork — с него и начинаем.»

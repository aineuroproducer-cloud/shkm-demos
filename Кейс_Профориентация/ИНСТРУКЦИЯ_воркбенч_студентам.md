# Воркбенч: инструмент, который собрался сам

Страница, куда вы вставляете профориентационный отчёт и получаете разбор с гипотезами
и черновик итогового отчёта. Никто не писал этот код руками — задача была описана словами,
Claude Code собрал страницу.

---

## Как открыть

**Вариант 1 — по ссылке.** [вставьте ссылку на GitHub Pages]
Открывается в любом браузере, на компьютере и на телефоне. Ничего скачивать не надо.

**Вариант 2 — файлом.** Скачайте `otchet-workbench.html` и откройте двойным кликом.
Работает без интернета в демо-режиме.

---

## Демо-режим: работает сразу, ничего настраивать не нужно

1. Нажмите **«Ясмина, 16»** или **«Максим, 34»** — отчёт подставится сам
2. Нажмите **«Проанализировать отчёт»**
3. Смотрите две вкладки:
   - **Анализ и гипотезы** — то, что вы читаете ДО консультации
   - **Итоговый отчёт** — черновик документа, который отдаёте ПОСЛЕ
4. **«Скачать .md»** — файл сразу можно положить в папку клиента

Этого достаточно, чтобы понять идею. Дальше — по желанию.

## Live-режим: свой ключ, любой отчёт

Если хотите прогонять свои отчёты, нужен **API-ключ**.

> ⚠️ **API-ключ — это не подписка Claude Pro и не подписка ChatGPT Plus.**
> Это отдельная вещь с отдельной оплатой по факту использования. Подписка не даёт
> доступа к API, и наоборот. Если у вас есть Pro — ключа у вас пока нет.

### Где взять ключ

**Anthropic (Claude):** console.anthropic.com → регистрация → Settings → API Keys →
Create Key. Пополнить баланс минимум на 5 долларов.

**OpenAI (GPT):** platform.openai.com → API keys → Create new secret key.
Тоже нужен положительный баланс.

### Сколько это стоит

Один разбор отчёта — примерно 2–5 центов. Пяти долларов хватает на сотню-другую прогонов.
Списывается по факту, абонентской платы нет.

### Как подключить

1. Нажмите **⚙️ Подключить live-режим**
2. Выберите провайдера
3. Вставьте ключ → он сохраняется **только в вашем браузере** и уходит напрямую
   в API выбранной компании. Ни на какой промежуточный сервер он не попадает.

### Если что-то не работает

| Симптом | Обычная причина |
|---|---|
| «Ошибка авторизации» | ключ скопирован не полностью или с пробелом |
| «Недостаточно средств» | баланс на счёте API нулевой — подписка тут не считается |
| Ничего не происходит | ключ вставлен, но не выбран провайдер |
| Работает в демо, но не с моим отчётом | проверьте, что ключ введён именно в ⚙️, а не в поле отчёта |

## Что с этим делать дальше

Этот воркбенч — **пример**, а не готовый продукт для вашей практики. Смысл не в том,
чтобы им пользоваться, а в том, чтобы увидеть: инструмент под свою задачу собирается
из описания задачи.

Три уровня, на которых вы можете остановиться:

1. **Взять как есть** — если работаете с профориентационными отчётами по этой методике
2. **Попросить переделать под себя** — тот же путь, но ваша рубрика и ваши поля
3. **Собрать свой с нуля** — когда у вас уже есть отработанный промпт, который хочется
   отдать коллеге или помощнику

> Важно: это уровень «дорасти», а не «сделай сегодня». Начинать стоит с ассистента
> второго уровня — Claude Project или Custom GPT. Своя кнопка нужна тогда, когда
> инструментом должен пользоваться кто-то кроме вас.

## Безопасность

- Не загружайте отчёты реальных клиентов без их согласия
- Обезличивайте: ФИО, контакты, школа, компания
- Демо-персонажи Ясмина и Максим полностью вымышлены — их можно использовать
  как образец того, что должно остаться в тексте, а что убрать

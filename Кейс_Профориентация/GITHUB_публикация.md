# 🌐 Как выложить воркбенч в интернет (GitHub Pages)

Чтобы у `otchet-workbench.html` появился настоящий адрес-сайт для демо и для коллег.
Ты уже делала это с квизом — здесь короче. ⏱ 5 минут, терминал НЕ нужен.

## Способ 1 — через сайт (без терминала)
1. github.com → **New** repository. Назови, например, `profori-workbench`, поставь **Public** → **Create**.
2. Заранее на компьютере переименуй `otchet-workbench.html` → `index.html`.
3. В репозитории **Add file → Upload files**, перетащи `index.html`, внизу **Commit changes**.
4. **Settings → Pages** → Branch: `main`, папка `/ (root)` → **Save**.
5. Через 1–2 минуты появится ссылка: `https://твойлогин.github.io/profori-workbench/`.

## Способ 2 — через VS Code
```
cd "D:\Рабочие проекты\ШКМ\1_НА_ЗАПИСЬ\Кейс_Профориентация"
copy otchet-workbench.html index.html
git init && git add index.html && git commit -m "profori workbench"
git branch -M main
git remote add origin https://github.com/ТВОЙЛОГИН/profori-workbench.git
git push -u origin main
```
Затем **Settings → Pages → main → Save**.

## ⚠️ Безопасность ключа
- Файл публичный. **НЕ вписывай свой API-ключ в код** перед публикацией.
- В воркбенче ключ вводится через ⚙️ и хранится только в браузере того, кто открыл (localStorage).
- Демо-режим (Ясмина, Максим) на публичной версии работает без ключа.

## После публикации — два шага

1. Вставьте полученную ссылку в `ИНСТРУКЦИЯ_воркбенч_студентам.md` (первая строка раздела
   «Как открыть») — там стоит заглушка.
2. Проверьте ссылку в режиме инкогнито: демо-режим должен работать без всякого ключа.
